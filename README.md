# BIGGEST EMPIRE
Premium self-contained static website.

## Important
This version keeps the CSS inside `index.html`, so opening `index.html` directly in a browser will still show the full design.

## Deploy
Upload `index.html` to GitHub. On Render choose **Static Site**, connect the repository, leave Build Command empty, and use `.` as the Publish Directory.
